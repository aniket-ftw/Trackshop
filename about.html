LESSON 01 / 06

Connect the dots.

Install your own GTM container

Open each HTML page and find the Google Tag Manager comments. Paste the real script snippet into the marked head position, after the data layer initialization. Paste the noscript snippet immediately after the opening body tag. TrackShop ships without a container ID, so the local debug panel works before you connect an analytics account.

Create a Custom Event trigger in GTM with the exact event name shown in the panel. Create Data Layer Variables for the parameters you need. Use them in your GA4 event tag, then verify the tag in GTM Preview and the event in GA4 DebugView.

User action → Website interaction → dataLayer.push() → GTM Trigger → GTM Variables → GA4 Event Tag → GA4 DebugView
LESSON 02 / 06

A click is the beginning.

Understand the event names

TrackShop pushes GA4-style event names such as add_to_cart directly, without a _demo suffix. That keeps the Custom Event trigger name and GA4 event name aligned. The products are fictional, but the event structure is designed for realistic practice.

Look for the small practice labels beneath controls. Navigation also sends navigation_click; hero buttons send cta_click and custom_cta_click. These are distinct learning events: choose the one you want to use for a report. Each control has a unique ID for GTM click-trigger exercises.

event: "add_to_cart"
ecommerce.currency: "INR"
ecommerce.value: 2999
ecommerce.items: [{ item_id: "SKU001", item_name: "Running Shoes", price: 2999, quantity: 1 }]
LESSON 03 / 06

Follow the whole journey.

From product list to purchase

Browse the catalog for view_item_list. Open a product for select_item and view_item. Add two units to the cart and inspect the quantity and value. Decrease a quantity or remove the item to see remove_from_cart. Cart quantity increases send add_to_cart for the added units only.

Entering checkout with items sends begin_checkout. Confirm valid shipping fields for add_shipping_info, select a fake payment method for add_payment_info, then place the order. The confirmation page sends purchase once for that transaction in this browser. Reloading it will not send another purchase.

view_item_list → select_item → view_item
add_to_cart → view_cart → begin_checkout
add_shipping_info → add_payment_info → purchase
LESSON 04 / 06

Practice without personal data.

Forms, leads, and signups

Use a made-up name, email, phone number, and address in all forms. Form values stay on the page and are not persisted in orders or the cart. Analytics events contain the form ID and field ID only, never the value you typed.

The contact form sends generate_lead only after validation succeeds. The newsletter sends sign_up with method set to newsletter. Both also provide form_start and form_submit practice. The site does not send emails, subscribe you to anything, or create a real enquiry.

form_start { form_id: "contact-form" }
form_interaction { form_id, field_id }
form_submit { form_id: "contact-form" }
generate_lead { form_id: "contact-form" }
LESSON 05 / 06

Look beyond the checkout.

Video, scroll, and custom interactions

The home-page video is an explicit simulator. Press Play to start, then try the milestone buttons. Each milestone fires once per simulated play-through; press Play after Complete to begin again. Pause produces video_pause, while completion produces video_complete.

This long page sends scroll_depth at 25%, 50%, 75%, and 90%, once per threshold per page load. The percentage is calculated from the scrollable document distance. The playground adds popup, coupon-copy, phone-reveal, email-reveal, and sharing exercises.

scroll_depth { percent_scrolled: 50 }
video_progress { video_percent: 75, video_provider: "simulator" }
custom_cta_click { cta_name: "Book Demo" }
LESSON 06 / 06

Make every event count.

Check, compare, repeat

Open the Analytics Debug Panel to inspect event names, timestamps, and payloads. The panel keeps a short local history across pages. It shows what was pushed; it does not prove that a GTM tag fired or that GA4 received anything. Compare it with GTM Preview and GA4 DebugView.

Avoid duplicate collection: if GA4 enhanced measurement or GTM click tags already track an interaction, do not also send the same event through another tag. The brochure creates both download_click and file_download for practice; select one tracking approach. The outbound link creates outbound_click.

1. Perform one action.
2. Inspect the data layer.
3. Verify the GTM trigger and tag.
4. Confirm parameters in GA4 DebugView.
5. Repeat with a different product or quantity.
